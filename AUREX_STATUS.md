# AUREX status

Last verified: **2026-11-01**, Linux x86-64 sandbox, Rust 1.88.0 / Cargo 1.88.0.

## Milestone

**Phase 0 / Phase 1 partial.** A real CLI vertical slice is functional; the required
desktop + Android Phase 1 acceptance gate has **not** passed. No production release,
installer, or fully supported platform is claimed.

## Verified locally

- Four core/CLI workspace members with reproducible dependency-free Cargo.lock.
- Async provider contract backed by a bounded blocking-I/O executor (3 workers/32
  queued jobs in GUI configuration; CLI uses 2/16).
- Linux descriptor-relative root scope; no traversal through symlinks.
- Directory paging, name sort/filter, hidden entries and native filename identity.
- Regular-file streaming copies with byte-for-byte verification and anonymous
  staging; no-replace publication. Source data is never removed by copy.
- Same-filesystem move/rename, private directory creation, nonrecursive deletion.
- Read-only grants, fail/skip/keep-both transfer conflicts, cooperative cancellation,
  shared progress, UTF-8 previews capped at 256 KiB.
- Bounded navigation/tab model with independent histories and selection.
- **37 passing Rust tests**: 19 filesystem integration, 6 copy-fault regressions,
  4 navigation, 4 executor, 4 CLI integration; plus **10 Python engineering tests**.
- Formatting, Clippy with warnings denied, release build, and CLI smoke benchmarks.

## Implemented source, NOT accepted as working GUI

Dioxus dual panes, per-pane tabs/history/filter/paging, editable relative path,
selection, session bookmarks, copy/move/rename/new folder/permanent-delete dialogs,
per-file activity, cancel, text preview, dark/light tokens and narrow-layout switching.
These call real Rust providers, not fabricated data. Hosted compilation found
type/ownership errors; fixes were confirmed by successful native Linux and Windows
release builds at source 9bf7405. WebView behavior, focus management, shutdown and
keyboard/touch acceptance are NOT TESTED. Strict GUI dependency policy still fails;
no GUI runtime or production acceptance is claimed.

Dioxus **0.7.10** was verified against the official GitHub release and tagged source.
Both lockfiles are generated by Cargo; the GUI lockfile was resolved using official
crates.io index records fetched through GitHub, with Rust 1.88-compatible resolution.
**Resolution is not compilation or a dependency security/license audit.**

## Blockers

1. No preinstalled Rust. A user-local 1.88.0 compiler/tooling was bootstrapped from
   accessible npm `@rustbin` component packages, outside this repository. This is a
   development workaround, not a trusted release-toolchain provenance claim.
2. Official Rust distribution, crates.io index and crate tarball hosts are blocked by
   sandbox egress policy. GUI `cargo check --offline` fails on unavailable dependencies.
3. GTK/WebKit development libraries, display runtime, Android SDK/NDK and native
   Windows runtime are unavailable locally. Nothing was installed system-wide in
   the sandbox; hosted Ubuntu build prerequisites were installed on its disposable runner.
4. MT Manager official sites are unreachable; MT research remains incomplete.
5. Actual GitHub core jobs and CLI artifacts passed. Native GUI builds exposed
   compilation errors; fixes now pass native Linux/Windows release builds.
   Security jobs expose unresolved GUI advisories/license requirements. See the linked engineering report for runs.
